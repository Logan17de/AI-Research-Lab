# Experimental Evidence Ledger

**Last updated:** 2026-07-17

Every result is assigned a status:

- **VALID** — generated by a repaired causal pipeline or verified implementation;
- **EXPLORATORY** — a real observation whose experimental scope is too limited for a broad claim;
- **SUPERSEDED** — mechanically valid for its narrow question but replaced by a fairer protocol;
- **INVALIDATED** — cannot support the original scientific claim;
- **PROPOSED** — not yet tested.

### 2026-07-17 — Pythia small-data behavior

**Status: VALID observations; EXPLORATORY comparison**

Pythia-1.4B + MOD trained smoothly:

```text
Train PPL: approximately 11.57 → 1.17
Assistant validation PPL: 10.55 → 7.00 → 7.81 → 10.05 → 12.88
```

Pythia-2.8B full fine-tuning showed the same broad early-improvement and late-degradation pattern.

The shared turning point indicates that the small mixed Q&A dataset and validation design dominate late-stage PPL. It is not sufficient evidence that either architecture wins.

Generation observations:

- both variants learned several taught facts;
- MOD sometimes produced cleaner factual answers and useful semantic reframing;
- MOD was weaker on unseen arithmetic, concrete procedures, and rarely trained token combinations;
- the 2.8B baseline was generally stronger at practical composition, but still hallucinated and failed harder extrapolation;
- neither model is a clean winner.

See [2026-07-17 Pythia Token MOD Findings](research-log/2026-07-17-pythia-token-mod.md).

## Superseded Evidence

### 2026-07-16 — 500-step dedicated-EOT quality gate

**Status: SUPERSEDED by pretrained EOS**

| Variant | Content PPL | First PPL | EOT PPL | EOT probability | EOT stops | Repeat-3 |
|---|---:|---:|---:|---:|---:|---:|
| Full | 5.84 | 33.97 | 936,959 | 0.000007 | 0/20 | 42.8% |
| MOD | 6.47 | 38.88 | 440 | 0.0867 | 7/20 | 38.3% |
| LoRA | 6.06 | 23.17 | 51.1 | 0.1753 | 0/20 | 48.5% |

Required gates were stop rate ≥80% and repeated-trigram rate ≤25%. Every model failed.

This run was useful because it showed that a newly added output token created a fairness problem. The experiment therefore returned to GPT-2 EOS.

### Earlier three-family global MOD design

**Status: SUPERSEDED on 2026-07-17**

The earlier Pythia design reused global Attention and FFN projections at every layer. It demonstrated low-overhead token-conditioned residual memory, but it did not provide the intended layer-specific interpretation.

The four-family architecture replaces it for the principal Pythia experiment.

### Early low-PPL long GPT-2 runs

**Status: INVALIDATED**

Former curves such as MOD PPL 782.76 → 4.34 and Full PPL → 1.95 were produced before the causal repair.

Free generation—empty answers, prompt copying, loops, repetition, and premature stopping—triggered the audit.

### Qwen/Tülu low-PPL run

**Status: EXPLORATORY, not comparative evidence**

The run was stable, but the starting “Base” checkpoint already showed assistant bias. It cannot cleanly establish how much SFT capability MOD created.

## Current Unsupported Claims

Not established:

- Token MOD matches or beats fully fine-tuned Pythia-2.8B;
- MOD is better than Full fine-tuning or LoRA in general;
- MOD preserves pretrained knowledge better;
- MOD generalizes algorithmic rules as well as dense training;
- analytical MAC estimates predict measured latency;
- lower teacher-forced PPL means healthy free generation;
- current results establish continual-learning superiority.

## Evidence Required Next

4. Evaluate rephrasing, held-out facts, composition, procedures, and arithmetic separately

6. Measure untouched-pretraining retention
7. Measure free generation, stopping, and repetition
8. Benchmark latency, throughput, VRAM, and wall-clock cost
9. Run multiple seeds
